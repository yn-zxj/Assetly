Features

一个应用，管住全屋的资产

从一件耳机到一整柜药品，物语把「买了什么、放在哪、还剩多少、什么时候过期」串成一条线。

物品与资产台账

购入日期、价格、条码、质保与退役记录，自动算出持有天数与日均成本。

空间树与收纳贴纸

多级空间索引，任意一层都能生成二维码标签，扫一下就看得到柜子里全部物品。

家庭药箱

有效期、库存与服用说明一目了然，本地通知准时提醒，打卡自动扣减库存。

扫码与 AI 识别

扫条码直接带出型号，或拍一张照片交给多模态模型，自动补全表单字段。

WebDAV 云同步

把备份推到你自己的坚果云或任意 WebDAV 空间，账号存在系统安全区，不进备份文件。

本地优先与离线可用

SQLite 直接落在设备上，飞行模式也照常用；没有账号体系，也就没有服务端泄露面。

安装步骤

  1. 点击上面的安装包下载到手机。
  2. 在文件管理里打开 APK，允许浏览器或文件管理器安装未知应用。
  3. 安装完成后直接打开，数据全部保存在本机。
  4. 旧版本可在「设置 → 检查更新」里升级，或到 Releases 页面下载。
